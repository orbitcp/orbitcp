# Security policy

Please **don't** report security problems in public issues or discussions.

Email **support@orbitcp.pro** with the subject "Security" and include:

- what you found and where (panel page, API endpoint, installer, portal)
- the steps to reproduce it
- the OrbitCP version (`orbitcp version` on the server)

We reply within 3 working days, keep you updated while we fix it, and credit you in the changelog if you like.

## Supported versions

Security fixes go into the newest release. Upgrade with:

```bash
curl -fsSL https://orbitcp.pro/install.sh | sudo bash
```
